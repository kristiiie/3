# Автоматизация подготовки наградных документов

Проект решает задачу массовой подготовки наградных документов для всероссийского конкурса творческих работ детей. Вместо ручного заполнения каждого диплома, сертификата и благодарственного письма используется таблица с данными и шаблон Word с полями слияния.

## Состав решения

| Файл | Назначение |
|---|---|
| `generate_awards_data.py` | Генератор CSV-таблицы с 330 строками данных. |
| `create_template.py` | Генератор DOCX-шаблона с полями `MERGEFIELD` для Word. |
| `generate_documents.py` | Программное формирование итогового DOCX-файла из CSV. |
| `awards_data.csv` | Таблица данных для слияния, разделитель `;`, кодировка UTF-8 with BOM. |
| `awards_data.xlsx` | Та же таблица в формате Excel для просмотра и редактирования. |
| `award_template_merge_fields.docx` | Шаблон наградного документа с полями слияния Word. |
| `award_documents_merged.docx` | Редактируемый итоговый файл с 330 наградными документами. |
| `award_documents_merged.pdf` | Нередактируемая PDF-версия итогового файла. |
| `requirements.txt` | Зависимости Python для генерации DOCX. |

## Логика данных

Одна строка таблицы соответствует одному наградному документу. В таблице сформированы три вида документов:

- дипломы за призовые места;
- сертификаты участников;
- благодарственные письма педагогам.

В файле `awards_data.csv` создано 330 строк, что соответствует требованию «не менее 300». Распределение в контрольном наборе:

| Вид документа | Количество |
|---|---:|
| Диплом | 60 |
| Сертификат участника | 240 |
| Благодарственное письмо | 30 |
| Всего | 330 |

## Поля слияния

Шаблон использует следующие поля:

| Поле | Содержание |
|---|---|
| `document_id` | Регистрационный номер документа. |
| `document_type` | Вид документа. |
| `title_text` | Заголовок: диплом, сертификат или благодарственное письмо. |
| `award_text` | Формулировка действия: награждается, подтверждает участие, выражается благодарность. |
| `recipient_name` | Получатель документа. |
| `recipient_role` | Роль получателя. |
| `child_name` | ФИО участника конкурса. |
| `teacher_name` | ФИО педагога. |
| `place` | Призовое место или отметка об участии. |
| `nomination` | Номинация конкурса. |
| `age_group` | Возрастная группа. |
| `work_title` | Название конкурсной работы. |
| `contest_name` | Название конкурса. |
| `organizer` | Организатор конкурса. |
| `city` | Город выдачи. |
| `issue_date` | Дата выдачи. |
| `signature_role` | Должность подписанта. |
| `signatory_name` | ФИО подписанта. |
| `note` | Дополнительная формулировка для документа. |

## Запуск проекта

1. Установить Python 3.10 или новее.
2. Перейти в папку проекта.
3. Установить зависимость:

```bash
pip install -r requirements.txt
```

4. Сформировать таблицу данных:

```bash
python generate_awards_data.py
```

5. При необходимости пересоздать шаблон Word:

```bash
python create_template.py
```

6. Сформировать итоговый DOCX:

```bash
python generate_documents.py
```

После запуска появится файл `award_documents_merged.docx`. Если на компьютере установлен LibreOffice, скрипт также попытается создать `award_documents_merged.pdf`. Если LibreOffice отсутствует, PDF можно сохранить вручную через Microsoft Word: **Файл → Сохранить как → PDF**.

## Как выполнить слияние через Microsoft Word

Готовый итоговый файл уже сформирован программой, но для демонстрации требования с «Мастером слияния» можно повторить операцию в Word вручную.

1. Открыть `award_template_merge_fields.docx`.
2. Перейти на вкладку **Рассылки**.
3. Нажать **Начать слияние** и выбрать тип **Письма**.
4. Нажать **Выбрать получателей → Использовать существующий список**.
5. Выбрать файл `awards_data.csv`.
6. Если Word попросит указать разделитель, выбрать точку с запятой `;`.
7. Нажать **Просмотреть результаты** и проверить несколько записей.
8. Нажать **Завершить и объединить → Изменить отдельные документы → Все**.
9. Сохранить полученный документ в формате DOCX.
10. Выполнить **Файл → Сохранить как → PDF** для нередактируемой версии.

## Что прикрепить к заданию

К ответу на задание нужно прикрепить:

1. `awards_data.xlsx` или `awards_data.csv` — таблицу данных;
2. `award_template_merge_fields.docx` — шаблон с полями слияния;
3. `award_documents_merged.docx` — редактируемый итоговый файл;
4. `award_documents_merged.pdf` — нередактируемый итоговый файл;
5. ссылку на репозиторий с программой и README.
